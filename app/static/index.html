À savoir avant de présenter
  • Sur l'offre gratuite de Render, le service se met en veille après ~15 min d'inactivité : le premier appel peut prendre jusqu'à une minute.
  • La base SQLite est stockée dans le conteneur : les données peuvent être perdues à chaque redémarrage ou redéploiement. Utilisez « Charger des exemples » pour repartir.
  • Projet pédagogique : aucune donnée personnelle réelle, uniquement des noms fictifs.
